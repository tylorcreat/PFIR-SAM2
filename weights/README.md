# Pretrained weights

This directory does not contain third-party SAM2 weights or large model files.

Place the two independently obtained files here when using the example configs:

- `sam2.1_hiera_large.pt`: official SAM2.1 Hiera-L base checkpoint, obtained from
  the official SAM2 repository.
- `PFIR-SAM2_OrganoID_best_model.pth`: retained PFIR-SAM2 OrganoID checkpoint.

The PFIR-SAM2 checkpoint is distributed separately from the Git repository
because it is approximately 1.03 GiB. Its release URL will be added after the
model asset has been deposited.
