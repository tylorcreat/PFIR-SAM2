# Reproduction

## Scope

The repository supports the core chain:

```text
public dataset -> dense-cue inference -> cue-guided reconstruction
-> uint16/uint32 instance TIFF -> unified metrics
```

It does not include raw datasets, third-party source trees, publication-layout
scripts, manuscript files, historical experiments, or third-party checkpoints.

## Strict model loading

`scripts/infer.py` reconstructs the retained architecture from checkpoint
metadata, initializes lazy feature projections, compares all parameter names and
shapes, loads with `strict=True`, and requires exactly 195 LoRA-wrapped `Linear`
modules. A load audit is written beside the inference outputs.

The PFIR checkpoint does not replace the official SAM2.1 Hiera-L base
checkpoint. Both are required: the base checkpoint constructs the SAM2 encoder,
then the retained PFIR state dictionary supplies the trained LoRA, CNN, fusion,
decoder, and saved encoder state.

## Inference protocol

The OrganoID and OrgaSegment configs use 800 x 800 tiles, 200-pixel overlap,
Hann blending, SAM normalization, and the same frozen reconstruction/rescue
parameters. Do not tune thresholds on Test.

## Evaluation protocol

At IoU 0.5, predictions and ground-truth instances are sorted by pairwise IoU
and greedily matched one-to-one. Pooled precision, recall, and F1 are computed
from TP/FP/FN summed across images. Mean per-image values are arithmetic means
of image-level metrics.

`P@0.75` is fixed-threshold precision at IoU 0.75. `mP@0.50:0.95` is the mean
of fixed-IoU-threshold precision values from 0.50 through 0.95 in steps of 0.05;
it is **not confidence-ranked COCO mAP**.

Count, total-area, and mean-instance-area MAPE are means of per-image absolute
percentage errors. Small Recall uses Train-area-tertile size groups generated by
`scripts/prepare_organoid.py`.

## Training protocol

The public YAML records the retained full-retraining settings: 100 epochs,
batch size 1, AdamW, learning rates 1e-4, weight decay 1e-4, cosine annealing,
AMP, seed 42, 800-pixel crop/whole-image size, and checkpoint selection by Val
foreground Dice. Test is not used for selection.

The training entry performs a provenance check against the retained PFIR
checkpoint before launching. This preserves the exact formal architecture and
saved defaults. It does not initialize trainable PFIR weights from that
checkpoint; model initialization still begins from the separately supplied
SAM2.1 Hiera-L base checkpoint.
